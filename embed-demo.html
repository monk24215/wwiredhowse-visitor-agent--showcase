Agent Widget — Demo

The chat launcher should appear in the bottom-right corner of this page.

Embed snippet

Drop these two scripts into the <body> of any HTML page. Replace HOST with where you deployed this folder.

<script>
  window.AGENT = {
    host: 'https://agent.example.com',
    slug: 'resume',
    title: 'Ask About Kristian',
    accent: '#e8a020',
    chips: ['Experience', 'Projects', 'Contact']
  };
</script>
<script src="https://agent.example.com/widget.js" defer></script>

Configuration

  • host (required) — base URL where the agent folder lives, no trailing slash
  • slug (required) — which agent to load (matches the slug in admin)
  • title — header shown in the modal (defaults to "Assistant")
  • greeting — first message shown when modal opens (overrides admin default)
  • accent — any CSS color for the launcher and buttons
  • chips — array of suggested-question buttons
