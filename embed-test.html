Resume Agent — Embed Test Page

This page demonstrates the widget. The chat launcher should appear in the bottom-right corner.

To embed on any site

Drop these two script tags into the <body> of any HTML page:

<script>
  window.RESUME_AGENT = {
    proxyUrl: 'https://your-domain.com/resume-agent-proxy.php',
    name:     'Ask About Kristian',
    greeting: "Hi — I can answer questions about Kristian's background, experience, and projects.",
    accent:   '#1a1a1a'
  };
</script>
<script src="https://your-domain.com/resume-agent-widget.js" defer></script>

Configuration options

  • proxyUrl (required) — full URL to resume-agent-proxy.php on your server
  • name — header label shown in the modal
  • greeting — first message shown when modal opens
  • accent — any CSS color (hex, rgb, named) for the launcher + buttons
